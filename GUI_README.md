# PhotoFinder — приложение для Windows

## Быстрый старт

1. Распакуйте **всю** папку PhotoFinder. Файл PhotoFinder.exe должен оставаться рядом с папкой _internal.
2. Откройте PhotoFinder.exe. Установка Python не требуется для собранного приложения.
3. Выберите 15–30 эталонных снимков одного человека. На каждом должно быть только одно лицо.
4. Выберите минимум 3 отдельных фото с человеком и минимум 3 без него. Не повторяйте эталоны и не добавляйте переименованные дубликаты.
5. Укажите папку поиска и папку результатов.
6. CPU выбран по умолчанию. Для NVIDIA нажмите «Проверить GPU» и после успешной проверки выберите GPU сами.
7. Нажмите «Проверить примеры» или сразу «Начать поиск»: проверка примеров выполняется перед каждым поиском.
8. После окончания нажмите «Открыть результаты».

Нужны Windows x64 и свободное место под копии фотографий. AMD/ARM GPU не поддерживаются; на Windows x64 без NVIDIA используйте CPU. Для NVIDIA требуется установленный совместимый драйвер.

## Первый запуск и модель

Если модель не включена в сборку, при первой проверке GPU или начале обработки потребуется интернет: InsightFace скачает buffalo_l. Интерфейс остаётся доступным, но загрузка модели не показывает процент скачивания. Остановка сработает после завершения текущей загрузки или файла.

Модель хранится в `%LOCALAPPDATA%\PhotoFinder\models\models\buffalo_l`. Если в сборку включён bundled_models, программа копирует модель в этот каталог при первом использовании. Фотографии и эмбеддинги обрабатываются локально.

## Устройства

CPU доступен сразу и выбран при каждом открытии. GPU включается только после загрузки CUDA и успешного тестового выполнения обеих моделей. Проверка сама не переключает устройство. При ошибке GPU можно выбрать CPU; скрытого переключения во время поиска нет.

## Проверочные фотографии

Три примера каждого типа — быстрая проверка, а не надёжная автоматическая калибровка. Пороги не меняются автоматически. Результат показывает найденные, сомнительные и ошибочные совпадения. Пропуски, ложные совпадения и ошибки анализа отдельных примеров выводятся как предупреждение и не блокируют поиск. Счётчик «Технических ошибок» относится к чтению и обработке файлов, а не к качеству распознавания. «Проверить примеры» выполняет только проверку; «Начать поиск» проверяет примеры и продолжает обработку основной папки.

В результатах проверки есть positive/negative CSV, JSON, JSONL и sample_check.json. Пропущенные эталоны перечислены в references.json. При повторной проверке создаётся новая папка результата.

## Результаты

- me — найден человек с высоким сходством;
- uncertain — нужен ручной просмотр, в том числе фото без найденных лиц;
- not_me — сходство найденных лиц ниже порога.

Оригиналы не изменяются. Копии сохраняют формат и вложенные пути. Без копирования (в дополнительных настройках) сохраняются только отчёты. Каждый запуск создаёт новый результат; автоматического возобновления нет.

Со спины, при перекрытом лице или на плохом кадре человек может быть пропущен. Проверяйте uncertain и выборку not_me. Приоритет полноты регулируется нижним порогом: его снижение сокращает число not_me, увеличивая ручную проверку.

## Ошибки

Журнал приложения: `%LOCALAPPDATA%\PhotoFinder\application.log`. Журнал конкретного запуска: run.log в папке результата. Если обработка остановлена, готовые записи остаются в отчётах; status.json отмечает отмену.

Для закрытия во время обработки сначала нажмите «Остановить», дождитесь текущей операции, затем закройте окно. GPU может быть недоступен в CPU-сборке или при проблемах драйвера/CUDA.

## Для разработчика: запуск из исходников

Из папки с photo_finder_gui.py:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip setuptools wheel
.\.venv\Scripts\python.exe -m pip install -r requirements-gpu.txt
.\.venv\Scripts\python.exe photo_finder_gui.py
```

Для CPU замените requirements-gpu.txt на requirements.txt. Не устанавливайте обе версии ONNX Runtime вместе. Для InsightFace при сборке из исходников могут понадобиться MSVC и Windows SDK из Visual Studio Build Tools.

## Сборка переносимого приложения

Сборка выполняется на Windows x64. Получатель готовой папки не устанавливает Python и зависимости.

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller==6.22.3
.\.venv\Scripts\python.exe build_windows.py
```

Результат: `dist\PhotoFinder\PhotoFinder.exe`. Передавайте всю папку `dist\PhotoFinder` в ZIP. Один EXE без _internal не работает. GPU-сборка включает крупные библиотеки NVIDIA и занимает несколько гигабайт; она также работает на CPU.

Для включения заранее полученных моделей:

```powershell
.\.venv\Scripts\python.exe build_windows.py --models '.\models\models\buffalo_l'
```

Готовые модели InsightFace имеют отдельные условия, заявленные авторами как non-commercial research only. Проверьте их при распространении и перед коммерческим использованием: https://github.com/deepinsight/insightface/tree/master/python-package.

Сборка из исходников не заменяет проверку на чистом Windows-компьютере. Для проверки окна предусмотрен `PhotoFinder.exe --smoke-test`; для отдельного каталога данных — `--data-dir <путь>`.
