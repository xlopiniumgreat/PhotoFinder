# PhotoFinder

PhotoFinder — настольное приложение для Windows, которое сортирует фотографии по наличию выбранного человека. Вы задаёте эталонные снимки, проверочные примеры и папку с фотографиями. Приложение работает локально и сохраняет копии в отдельную папку, не меняя оригиналы.

**[Скачать последнюю версию для Windows](../../releases/latest)** · [Исходный код](.) · [Инструкция для пользователя](GUI_README.md)

## Скачать и запустить

1. Откройте [последний выпуск](../../releases/latest).
2. Для любого компьютера Windows x64 скачайте `PhotoFinder-Windows-CPU.zip`, распакуйте архив и запустите `PhotoFinder.exe`.
3. Чтобы включить NVIDIA GPU, скачайте также оба файла `PhotoFinder-NVIDIA-1-CuDNN.zip` и `PhotoFinder-NVIDIA-2-CUDA.zip`. Распакуйте их в ту же папку PhotoFinder с заменой при запросе. Затем запустите приложение и выберите GPU после проверки в окне.

Для CPU достаточно базового архива. GPU-архивы не нужны для AMD или компьютеров без NVIDIA. Для NVIDIA требуется актуальный совместимый драйвер. CPU выбран по умолчанию. Папку `_internal` и структуру архивов нужно сохранить.

При первом использовании приложению нужен интернет для загрузки модели распознавания `buffalo_l`. После загрузки изображения и результаты остаются на компьютере. Модель имеет отдельные условия распространения и использования; подробности приведены ниже.

## Возможности

- Поиск человека по нескольким эталонным фотографиям.
- Категории результата: `me`, `uncertain`, `not_me`.
- CPU или NVIDIA CUDA; режим CPU выбран по умолчанию.
- Форматы JPG, PNG, WebP, HEIC и HEIF.
- Проверочные фотографии с человеком и без него.
- Копирование найденных фотографий с сохранением подпапок и отчёты CSV/JSON.
- Оригиналы фотографий не изменяются.

Распознавание может пропустить человека со спины, при закрытом лице или на некачественном снимке. Проверяйте сомнительные результаты вручную.

## Для разработчиков

Нужен Windows x64 и Python 3.11. Создайте окружение и установите один набор зависимостей:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
# CPU:
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
# Или NVIDIA GPU вместо предыдущей строки:
.\.venv\Scripts\python.exe -m pip install -r requirements-gpu.txt
.\.venv\Scripts\python.exe photo_finder_gui.py
```

Не устанавливайте `requirements.txt` и `requirements-gpu.txt` в одно окружение одновременно: в них разные сборки ONNX Runtime.

Переносимую Windows-сборку создаёт workflow при публикации тега `v*`. Состав архивов настраивается в `scripts/pack_release.py`; локальная инструкция по PyInstaller находится в [GUI_README.md](GUI_README.md).

## Данные и лицензии

Приложение выполняет анализ на компьютере пользователя. Модель `buffalo_l` скачивается InsightFace при первом запуске и распространяется на условиях авторов модели; на странице InsightFace указано ограничение для предобученных моделей: некоммерческое исследовательское использование. Перед распространением моделей или любым коммерческим использованием изучите [условия InsightFace](https://github.com/deepinsight/insightface/tree/master/python-package). Релиз PhotoFinder не включает веса модели.

Исходный код PhotoFinder распространяется по лицензии MIT. Библиотеки в переносимой сборке имеют собственные лицензии; перечень сторонних зависимостей формирует GitHub Actions в каждом релизе.
