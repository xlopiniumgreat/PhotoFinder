# Как помочь проекту

Сообщайте об ошибках через GitHub Issues. Не прикладывайте личные фотографии, эталонные изображения, модели или журналы, в которых могут быть пути и имена файлов.

Для разработки используйте Python 3.11 x64 и отдельное виртуальное окружение. CPU-зависимости устанавливаются из `requirements.txt`, NVIDIA GPU-зависимости — из `requirements-gpu.txt`. Эти варианты ONNX Runtime нельзя устанавливать одновременно.

Перед отправкой изменений запустите имеющиеся тесты:

```powershell
python -m unittest discover -s . -p 'test_*.py'
```

Опишите в pull request проблему, ожидаемое поведение и способ ручной проверки.
